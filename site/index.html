01 // DEPLOYMENT PROTOCOL

Bare-metal flashing workflow.

  1. STEP 01

    Enter Bootloader

    Connect the Native USB OTG port on your ESP32-S3. Hold BOOT, plug in USB-C (or tap RST), then release BOOT.

    PORT: USB JTAG / SERIAL
  2. STEP 02

    Flash via Web Serial

    Select Super Mini or N16R8 above, click Connect & Flash, choose your serial port, and write the merged factory image.

    OFFSET: 0x0000 // FACTORY BIN
  3. STEP 03

    Reset & Control

    Press RST after verification finishes. RubberOrca enumerates as a wired USB HID peripheral and advertises BLE 0xFFE0.

    MODE: HID + BLE READY
02 // HARDWARE ARCHITECTURE

Engineered without bridge bottlenecks.

USB STACK

Native USB-OTG Composite HID

ESP32-S3 handles USB directly in silicon via TinyUSB. Low-latency Keyboard, Mouse, and Consumer Control descriptors plus UTF-8 Turkish Q and US layouts across macOS, Windows, and Linux.

NVS STORAGE
16SLOTS

Wear-leveled ESP32 NVS stores 16 macro chains (m0..m15), BLE name, passkey, and layout.

WIRELESS

BLE 5.0 GATT + Hardening

Compatible with RubberOtter 0xFFE0/0xFFE1 clients, with optional 6-digit static passkey bonding and RGB status LED.

ECOSYSTEM & DELIVERY

SDK, CLI, MCP & Automated Releases

Install via brew install AtaCanYmc/tap/rubberorca or pip install rubberorca for Python SDK, CLI, and stdio MCP server (rubberorca-mcp). Every tagged GitHub Release builds both factory binaries and updates this flasher.
