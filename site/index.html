01 // DEPLOYMENT PROTOCOL

Three steps to bare-metal ready.

+
STEP 01

Enter Bootloader

Use the Native USB OTG port on your ESP32-S3. Hold the BOOT button, plug in the USB-C cable (or tap RST), then release BOOT.

PORT: USB JTAG / SERIAL
+
STEP 02

Flash via Web Serial

Select Super Mini or N16R8 above, click Connect & Flash, choose your ESP32-S3 serial port, and let ESP Web Tools write the merged factory image.

OFFSET: 0x0000 // FACTORY BIN
+
STEP 03

Reset & Control

Press RST after verification completes. RubberOrca enumerates as a wired USB HID device and advertises BLE 0xFFE0 for the Python SDK, CLI, MCP, and RubberOtter clients.

MODE: HID + BLE READY
02 // HARDWARE ARCHITECTURE

Engineered without bridge bottlenecks.

USB STACK

Native USB-OTG Composite HID

ESP32-S3 handles USB directly in silicon via TinyUSB. Low-latency Keyboard, Mouse, and Consumer Control descriptors plus UTF-8 Turkish Q and US layouts across macOS, Windows, and Linux.

STORAGE & RAM
16SLOTS

Wear-leveled ESP32 NVS stores 16 macro chains (m0..m15), BLE name, passkey, and layout.

WIRELESS

BLE 5.0 GATT + Hardening

Compatible with RubberOtter 0xFFE0/0xFFE1 clients, with optional 6-digit static passkey bonding and RGB status LED.

ECOSYSTEM & DELIVERY

SDK, CLI, MCP & Automated Releases

Install pip install rubberorca for Python SDK, CLI, and stdio MCP server (rubberorca-mcp). Every tagged GitHub Release builds both factory binaries and updates this flasher.
